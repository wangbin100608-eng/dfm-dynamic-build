## 1.3 Binder / BinderFS / 共享内存

| 项 | 实测 |
|---|---|
| `/dev/binder` | 不存在（被 binderfs 替代） |
| `/dev/hwbinder` | → `/dev/binderfs/hwbinder` |
| `/dev/vndbinder` | → `/dev/binderfs/vndbinder` |
| binderfs 挂载 | 3 个 `binder on /dev/binderfs type binder (rw,relatime,max=1048576)` |
| binderfs 节点 | binder(237,13) / hwbinder(237,14) / vndbinder(237,15) / anbox-* / binder-control |
| `/dev/ashmem` | 存在，crwxrwxrwx，10:123；模块 `ashmem_linux` 已加载 |
| `/dev/shm` | tmpfs 16G |
| `CONFIG_SHMEM=y`, `CONFIG_MEMFD_CREATE=y` | 内核支持 |
| 模块 | `binder_linux 217088`, `ashmem_linux 20480` |

**结论**：Binder/BinderFS/ashmem 齐全，满足 Android 容器化条件。
